# OSS, IP, and Branding Notes

## Purpose

This note explains the intended public posture of Invariant as an open source
EchoForgeX project.

## Open Source License

Invariant is released under the Apache License 2.0.

That means the software in this repository is intended to be distributed and
used as open source software under the terms of that license.

EchoForgeX may own intellectual property, including patents, related to the
broader framework, methods, architecture, and future commercial implementations
connected to this work.

The purpose of the open source release is:
- to distribute the testing harness and operator console openly
- to promote adoption and validation of the system-level security approach
- to support the larger EchoForgeX injection prevention framework direction

The open source release is not intended as a patent enforcement vehicle against
normal use of this repository under its license.

## Practical Interpretation

For public users, the practical message is:

- the repository is open source software
- the code may be used under Apache-2.0
- EchoForgeX retains its brand identity and broader strategic framework
